# Hackathon Submission Checklist

This checklist ensures all hackathon requirements are met for submission.

## ✅ Mandatory Requirements

### 1. Video Recording (5-10 minutes)
- [ ] Recorded demo showing workflow in action
- [ ] Explains problem and solution clearly
- [ ] Demonstrates working end-to-end functionality
- [ ] Shows AI doing meaningful work
- [ ] Describes real-world impact
- [ ] File placed in submission Drive folder

### 2. Problem Statement & Solution Document
- [ ] Word/PDF/PPT document explaining:
  - [ ] Specific real-world problem (exam prep inefficiency)
  - [ ] Who it's for (students preparing for exams)
  - [ ] How our solution solves it (AI-powered personalization)
  - [ ] Why AI is essential (impossible to do manually at scale)
- [ ] Document placed in submission Drive folder

### 3. Drive Folder Structure
- [ ] Parent folder: "AI Exam Prep - Hackathon Submission"
- [ ] Sub-folder 1: "Documentation" (Problem statement document)
- [ ] Sub-folder 2: "Demo" (Video recording)
- [ ] Sub-folder 3: "Workflow" (exam-prep-workflow.json, sample-data.json)
- [ ] Sub-folder 4: "Screenshots" (Workflow screenshots, results)

### 4. Drive Sharing Settings
- [ ] Shared with product@houseofedtech.in as Editor
- [ ] General Access set to "Anyone with the link · Viewer"
- [ ] Both settings verified and working

### 5. Google Form Submission
- [ ] Form filled out completely
- [ ] Drive folder link pasted correctly
- [ ] Three questions answered:
  - [ ] Problem statement (specific, quantified)
  - [ ] Target audience (students, professionals)
  - [ ] AI usage explanation (personalization, adaptation)
- [ ] All under 100 words each

### 6. LinkedIn Post
- [ ] Posted announcing the project
- [ ] Tagged @Be10X
- [ ] Posted before May 5th midnight IST
- [ ] Highlights key benefits and demo

### 7. Website Hosting (If applicable)
- [ ] Frontend hosted on free platform (if built)
- [ ] Link is publicly accessible
- [ ] Working demo available

## 🎯 Evaluation Criteria Readiness

### Problem Framing (25 pts)
- [ ] Problem is clearly articulated as real and specific
- [ ] Impact is quantified (5-10 hours weekly saved)
- [ ] User type is clearly identified (students, professionals)
- [ ] Problem comes from real user frustration

### AI Leverage & System Design (30 pts)
- [ ] AI is used thoughtfully, not decoratively
- [ ] AI does work that humans cannot do at scale
- [ ] Removing AI would break the solution
- [ ] System design is clear and logical

### Practical Usefulness (20 pts)
- [ ] Solution saves measurable time and effort
- [ ] Impact on user outcomes is clear
- [ ] Real use cases demonstrated
- [ ] Not just technical demo but practical tool

### Execution Quality (15 pts)
- [ ] Works end-to-end without issues
- [ ] Usable by target audience
- [ ] Clear instructions for setup and use
- [ ] Reliable and consistent outputs

### Clarity of Explanation (10 pts)
- [ ] Problem and solution clearly articulated
- [ ] Value proposition is obvious
- [ ] Technical aspects explained accessibly
- [ ] Demo video is clear and engaging
